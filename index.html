Overview

CryptoShare — Trust Capsule

A hybrid cryptographic secure communication and cryptography learning framework. Two distinct layers, kept deliberately separate: a classical cryptography lab for learning, and a modern Trust Capsule workflow for secure communication.

Layer 1

Classical Cryptography Lab

Playfair and Hill ciphers, fully worked with step-by-step matrix and digraph visualization. Educational only — not suitable for real confidentiality.

Layer 2

Trust Capsule

AES-GCM confidentiality, ECDH session establishment, SHA-256 integrity, and ECDSA signatures — assembled into a single verifiable capsule using the Web Crypto API.

Cryptographic Journey

Trace a message from input to output across every stage: encryption, key establishment, integrity, authentication, and verification.

Security Analysis

A side-by-side comparison of Playfair, Hill, AES-GCM, ECC/ECDH, SHA-256, and ECDSA — purpose, strength, and modern suitability.

Methodology & Scope

This project does not invent new cryptography. It applies established primitives inside a documented Trust Capsule workflow.

Layer 1

Classical Cryptography Lab

Hands-on, fully worked implementations of two classical ciphers. These modules exist to teach the mechanics of substitution and matrix-based encryption — they are never combined with the modern Trust Capsule pipeline.

Scope note: Playfair and Hill ciphers are historically significant but are not secure against modern cryptanalysis. They are presented here strictly as an educational sandbox.

Playfair Cipher

Digraph substitution cipher using a 5×5 key matrix. Covers matrix generation, I/J merge, and the three digraph rules.

Hill Cipher

Matrix-based polygraphic cipher using modular linear algebra. Covers determinant, modular inverse, and key invertibility.

          Reference
          
      About & Methodology
      
          
      CryptoShare — Trust Capsule is a university-level Cryptography & Network Security mini project.
      
        
      

        
      
          
      Scope statement
      
          
      This project does not invent new cryptographic algorithms. Playfair, Hill Cipher, AES-GCM, ECDH/ECC, SHA-256, and ECDSA are all established, well-documented techniques. The contribution of this project is the application-level Trust Capsule workflow that combines the modern primitives into a single, verifiable, educational secure-communication package.
      

          
      Layer separation
      
          
      The Classical Cryptography Lab (Playfair, Hill) and the Trust Capsule (AES-GCM, ECDH, SHA-256, ECDSA) are kept entirely independent. Classical cipher output is never fed into the modern pipeline, and the two are not chained together to imply additional security.
      

          
      Technology
      
          
      Built with HTML5, CSS3, and vanilla JavaScript. Modern cryptographic operations use the browser's native Web Crypto API. No backend, no external cryptography libraries.
